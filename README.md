**Proyecto finalizado y entregado.**

La aplicación contiene la implementación completa de los métodos numéricos establecidos para el proyecto universitario, junto con sus validaciones, tablas de resultados, gráficas y opciones de exportación.

## 🌐 Despliegue

La aplicación fue desarrollada como una SPA con React y Vite, por lo que puede ejecutarse localmente o desplegarse como un sitio web estático.

Para generar la versión de producción:

```bash
npm run build
```

Los archivos optimizados se generan en:

```text
dist/
```

Para revisar la versión de producción localmente:

```bash
npm run preview
```

## 🎓 Alcance académico

La aplicación fue desarrollada como proyecto universitario para el curso de Métodos Numéricos.

La plataforma permite estudiar y aplicar:

- Métodos para encontrar raíces de ecuaciones no lineales.
- Métodos de interpolación.
- Métodos iterativos para sistemas de ecuaciones lineales.
- Métodos para sistemas de ecuaciones no lineales.
- Criterios de convergencia.
- Análisis de errores.
- Influencia de los valores iniciales.
- Comportamiento de las aproximaciones.
- Interpretación de tablas de iteraciones.
- Representación gráfica de funciones.

---

## ⚠️ Consideraciones de uso

- Los resultados dependen de los datos ingresados por el usuario.
- Algunos métodos requieren condiciones específicas para converger.
- Las funciones deben respetar su dominio matemático.
- Los métodos iterativos pueden no converger para ciertos valores iniciales.
- Una tolerancia menor puede aumentar la cantidad de iteraciones.
- Los errores de redondeo pueden afectar las últimas cifras del resultado.
- Los resultados deben acompañarse de una interpretación matemática.
- La aplicación es una herramienta educativa y no sustituye el análisis teórico del problema.

---

## 🔒 Seguridad y tratamiento de datos

La aplicación funciona completamente del lado del cliente.

- No solicita información personal.
- No almacena datos en una base de datos.
- No transmite información a servidores externos.
- Los cálculos se realizan directamente en el navegador.
- Los archivos exportados son generados localmente.

## 🏁 Conclusión

La Aplicación Web de Métodos Numéricos centraliza diferentes algoritmos matemáticos en una plataforma interactiva, accesible y organizada por unidades.

La aplicación facilita la ejecución de procedimientos, el análisis de iteraciones, la interpretación de errores y la visualización de resultados. Su estructura basada en componentes permite presentar cada método de forma independiente y mantener una experiencia de uso consistente.

El proyecto cumple con el propósito de proporcionar una herramienta educativa de apoyo para estudiantes y docentes del curso de Métodos Numéricos.
